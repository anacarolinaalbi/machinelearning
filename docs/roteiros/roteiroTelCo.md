Base de Dados – Telco Customer Churn
Descrição Geral

A base Telco Customer Churn contém informações sobre clientes de uma operadora de telecomunicações, incluindo seus serviços contratados, perfil financeiro, permanência e forma de pagamento.
O objetivo principal é prever Churn — se o cliente cancelou ou não o serviço — caracterizando um problema de classificação binária.

Estrutura dos Dados

Dados demográficos: gênero, idade aproximada, presença de dependentes ou parceiro.

Informações contratuais: tipo de contrato (mensal, anual), forma de pagamento, fidelização.

Serviços contratados: internet, telefone, streaming, segurança online, backup, suporte técnico.

Informações financeiras: monthly charges, total charges, tenure (meses como cliente).

Variável-alvo: Churn (Yes/No).

Uso no Projeto

A base é aplicada para:

prever cancelamento de clientes,

analisar fatores que influenciam churn,

treinar modelos de classificação como Logistic Regression, SVM, Random Forest e Gradient Boosting,

apoiar estratégias de retenção baseadas em dados.
