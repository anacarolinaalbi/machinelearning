Base de Dados – Global Tech Gadget Consumption
Descrição Geral

A base Global Tech Gadget Consumption reúne informações demográficas, financeiras e comportamentais de consumidores de tecnologia em diferentes países.
Cada registro representa um cliente, contendo variáveis relacionadas a idade, renda, nível de interesse em tecnologia, padrão de compras de eletrônicos e engajamento digital.

O dataset permite compreender padrões globais de consumo de gadgets e serve como base para modelos de classificação, especialmente na previsão de intenção de compra ou segmentação de consumidores.

Estrutura dos Dados

Dados demográficos: idade, gênero, país.

Dados financeiros: renda estimada, poder de compra.

Comportamento digital: horas semanais de uso de tecnologia, engajamento online.

Histórico de compras: gastos anuais, categorias preferidas, recorrência de compra.

Variável-alvo (dependendo do modelo): propensão a compra, categoria de cliente ou segmentação.
