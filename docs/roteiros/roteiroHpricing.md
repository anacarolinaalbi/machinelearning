Base de Dados – House Pricing (train.csv)
Descrição Geral

A base House Pricing contém características detalhadas de imóveis residenciais da cidade de Ames (EUA).
Cada linha representa uma casa, descrevendo atributos estruturais, qualidade construtiva e características do terreno.
A variável-alvo é SalePrice, o preço de venda, tornando o dataset ideal para problemas de regressão.

Estrutura dos Dados

Informações estruturais: área construída, número de cômodos, banheiros, garagem, porão.

Qualidade e condição: qualidade geral do imóvel, materiais utilizados, acabamento.

Informações do terreno: tamanho do lote, zoneamento, posição do lote.

Datas importantes: ano de construção e ano de reforma.

Variável-alvo: SalePrice (valor numérico).

Uso no Projeto

A base permite:

treinar modelos de regressão (Linear, Ridge, Lasso, Random Forest, Gradient Boosting),

analisar impacto de variáveis no preço,

avaliar tendências de valor no mercado imobiliário,

testar pipelines de pré-processamento com dados mistos.
